📖 API 使用文档

1. 随机图片接口

GET /api/random

参数说明：

参数 类型 必填 说明
category string 否 分类slug（如：acg、wallpaper）
device string 否 设备类型：pc（横屏）或 mobile（竖屏）
不指定时自动从User-Agent识别，默认pc
output string 否 响应模式：redirect（默认，302重定向）、json（JSON数据）、proxy（代理图片）
compress boolean 否 是否压缩图片（仅proxy模式有效）：true 或 false（默认）
channel_id string 否 接入渠道标识：用于计量与独立限流（可在管理后台创建；不携带则计入匿名，受全局兑底限流）

使用示例：

# 最简单的用法（自动识别设备, 同源相对路径）
<img src="/api/random">

# 指定分类和设备
<img src="/api/random?category=acg&device=mobile">

# 获取JSON数据
curl "/api/random?output=json"

# 携带Channel（计量与独立限流）
curl "/api/random?channel_id=YOUR_CHANNEL&output=json"

2. 图片代理接口

GET /api/proxy/:id

参数说明：

参数 类型 必填 说明
id number 是 图片ID（路径参数）
compress boolean 否 是否压缩：true 或 false（默认）
format string 否 目标格式：jpeg、png

使用示例：

# 代理原图
<img src="/api/proxy/123">

# 压缩并转换为JPEG
<img src="/api/proxy/123?compress=true&format=jpeg">

3. 图片列表接口

GET /api/images

参数说明：

参数 类型 必填 说明
page number 否 页码（默认1）
page_size number 否 每页数量（默认20，最大100）
category string 否 分类slug
device string 否 设备类型：pc 或 mobile

4. 分类列表接口

GET /api/categories

使用示例：

curl "/api/categories"

🔑 接入说明

  • 公开访问：公开接口无需任何凭证，跨域默认放行（CORS 全局开放）
  • Channel：可携带 channel_id 参数，用于流量计量与独立限流；它不是秘密，可直接嵌在前端URL中
  • 匿名访问：不携带 channel_id 的请求计入匿名统计，受全局兑底限流保护
  • 管理API：需要在请求头添加 Authorization: Bearer ADMIN_TOKEN

⚡ 限流规则

  • 携带 channel_id：按 Channel 配置的限流规则（滑动窗口，默认 60 次/分钟）
  • 匿名请求：全局兑底限流（默认 300 次/分钟，可用 ANON_RATE_LIMIT 配置）
  • 超限返回 429，响应携带 X-RateLimit-Limit 与 X-RateLimit-Remaining

🚀 快速开始

# 获取随机图片（JSON格式）
curl "/api/random?output=json"

# 获取随机图片（302重定向）
curl -L "/api/random"

# 按分类获取
curl "/api/random?category=acg"
